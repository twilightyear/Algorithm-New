### [ Baekjoon ] 2490 : 윷놀이

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 도 개 걸 윷 모 등의 여부는 모든 조합을 따져 볼 필요 없이, 단순 정수의 합산으로 확인이 가능하다. 그렇기에, 입력값이 한줄로 들어오니, input().split() 로 공백 기준으로 구분하여 해당 값을 map 을 이용하여 int 로 변환하면서 list 로 저장한다. 이렇게 구성한다면 현재 문제에서 3줄에 각 4번씩 입력이 들어가는 형식으로 정해져 있으니, O(1) 의 시간복잡도와 공간복잡도를 가지게 된다.

### 📝 추후 개선점
  - 다른 실력 있는 사람의 풀이를 조금 시간을내서 찿아보다 충격적인 풀이방식을 발견했다. 이 문제를 단 한줄로 풀이한 것이다. 앞서 말한 정수의 합산으로 계산이 가능하다는 점에 근거하여, DCBAE 라는 문자열을 만들어두고, 합산값을 인덱스로 사용하여 조건문을 굳이 거치지 않는 영리한 방식을 사용한 것을 보았다. 이 방식에 리스트 컴프리헨션과 위에서 설명했던 입력을 받는 방식을 한줄에 구겨넣은 풀이였다. 가독성이 물론 떨어지긴 하다만, 접근 1번에서는 최악의 경우에서는 D 의 경우까지 전부 확인해야하지만, 문자열을 활용한 인덱스로 바로 접근하는 방식은 그럴 필요 없이 바로 접근이 가능하기에, 큰 시간적 차이는 없겠지만, 상수적인 시간복잡도 측면에서 빠르다라고 추측할 수 있다.

### 💻 풀이 코드

```python
# 풀이 1
for _ in range(3):
  arr = list(map(int, input().split()))
  val = sum(arr)

  if val == 4:
    print("E")
  elif val == 3:
    print("A")
  elif val == 2:
    print("B")
  elif val == 1:
    print("C")
  elif val == 0:
    print("D")
```
