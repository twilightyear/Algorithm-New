### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 생각보다 시행착오를 겪었던 문제다. 처음에는 아무 생각 없이, a 와 b 사이에 올 수 있는 값들의 개수인 b - a - 1 을 출력하고, range 로 값들을 출력하게 구성했더니 오답으로 나왔다. 생각해보니, a 와 b 의 대소관계를 마음대로 가정하고 풀었다는 생각을 해서 min, max 함수로 직접 대소관계가 꼬이지 않게 구성했다. 또한, a 와 b 가 같은 경우 원치 않는 값이 나오기에, 같은 경우에 있어서는 임의로 0을 출력하게 하고, 같지 않은 경우에는 b - a - 1 를 출력하게 했다.

### 📝 추후 개선점
  - 다른 사람들의 풀이를 살펴보니, 대체적인 풀이 방식은 동일했지만 마지막 출력 과정에서 for 문에서 print 문에서 end 를 사용하여 출력할 것인지, 아니면 리스트를 구성해서 join 함수로 출력할 것인지에 대한 여부가 갈렸다. 굳이 리스트를 만들어서 공간을 추가적으로 쓸 필요가 없기에, 순회 과정에서 바로 출력해버리는 print 가 공간복잡도 측면에서 낫다고 생각한다.

### 💻 풀이 코드

```python
# 풀이 1
arr = list(map(int,input().split()))
a = min(arr[0], arr[1])
b = max(arr[0], arr[1])

if a == b:
  print(0)
else:
  print(b - a - 1)
  
for i in range(a+1, b):
  print(i, end = " ")
```
