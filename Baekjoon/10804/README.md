### [ Baekjoon ] 10804 : 카드 역배치

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 1 부터 20 까지 저장한 리스트를 먼저 초기화해두고, 입력에 따라, 범위에 해당하는 영역을 y, 이전과 이후의 영역을 각 x 와 z 로 둔 다음, y 를 reverse 하여 전부 합치고 1 부터 20 까지 초기화해둔 값에 덮어씌운 것을 10번 반복한다. 이렇게 구성한다면 현재 문제에서 지정해준 반복 입력 횟수는 10회, 리스트의 길이는 20이니, O(1) 의 공간복잡도와 시간복잡도가 발생한다.

### 📝 추후 개선점
  - 너무 복잡하게 접근했던 것 같다. 슬라이싱을 어자피 쓸거라면, 굳이 reverse 를 쓸 필요도 없이 [::-1] 를 사용하면서 더 짧고 간결하게 코드를 구성할 수 있다는 것을 전혀 활용하지 못했다. 다른 사람들의 풀이를 살펴보니 많은 사람들이 reverse 함수를 명시적으로 사용하는 것이 많이는 않았다. 물론 문제에서 입력 횟수 등을 전부 정해준 문제이기에 O(1) 의 시간복잡도와 공간복잡도가 왠만해서는 변하지는 않지만, 내 풀이는 이러한 점에 있어서 파이썬 답게 푸는 풀이가 되지 못했던 것 같다.

### 💻 풀이 코드

```python
# 풀이 1
result = []
for i in range(20):
  result.append(i+1)

for _ in range(10):
  arr = list(map(int, input().split()))
  a, b = arr[0], arr[1]
  x = result[:a-1]
  y = result[a-1:b]
  z = result[b:]

  y.reverse()
  x.extend(y)
  x.extend(z)
  result = x

for n in result:
  print(n, end=" ")
```
