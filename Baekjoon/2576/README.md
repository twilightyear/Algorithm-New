### [ Baekjoon ] 2576 : 홀수

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 배열 입력을 받은 후, 리스트 컴프리헨션으로 미리 홀수만 추출하여 저장한다. 기존 배열은 보존할 필요가 전혀 없으니 덮어쓰기로 공간을 절약한다. 이후 차례대로 배열이 비었다면 0, 아니라면 배열의 합과 배열 값중 최소값을 출력하면 된다. 이렇게 구성한다면, 입력이 7개라는 것은 미리 지정되어있었으니, O(1) 의 공간복잡도와, O(1) 의 시간복잡도를 가진다. 문제에서 입력값의 개수를 적게 정해줘서 이렇게 된 것이지, 만약 제한이 없었다면 입력값의 개수 N 에 대하여 O(N) 시간복잡도와 공간복잡도를 가졌을 것이다.

### 📝 추후 개선점
  - 사실 어떻게든 다른 사람들 풀이를 찿아봤을때 풀이는 거의 동일했다. 문제가 딱히 크게 어렵지 않았던 만큼 풀이 방법도 크게 달라질 것도 없는 것이였다. 아무튼, 개선점은 그냥 넘어가도록 하겠다.
  
  - 백준 서비스가 정말 오랜만에 돌아왔기에, 바로 들어가서 가볍게 쉬운 문제 바로 하나 풀어보는 시간을 가져보았다. 백준은 다른 사람들 풀이를 한눈에 비교해보는 기능이 조금 부족한 것 같아 비교 과정을 어떻게 해야할지 살짝 고민이 된다. 앞으로 계속 여러 시도를 해봐야겠다.

  -이전에 바킹독님의 영상을 보면서 공부를 할때, 백준 서비스가 없었어서 문제집을 못 푼다는 것이 매우 아쉬웠던 점이 존재한다. 나름 Leet Code 를 통하여 유형 연습을 했지만 그래도 아쉬운건 마찬가지다. 그렇기에, 앞으로 바킹독님의 문제집의 문제를 위주로 풀어보며 연습해보겠다.

### 💻 풀이 코드

```python
# 풀이 1
arr = []

for _ in range(7):
  arr.append(int(input()))

arr = [n for n in arr if n % 2 != 0]

if len(arr) == 0:
  print(-1)
else:
  print(sum(arr))
  print(min(arr))
```
