### [ Programmers ] 문자열 정렬하기 (1)

### 🛠️ 풀이 접근 및 분석

  - **접근 1**
    - 문자열을 정렬하는 문제이기에, 먼저 문제에서 요구하는것처럼 문자의 모든 항목을 lower 를 통하여 소문자화 하고, 이후, 내장 정렬을 이용하여 정렬 및 join 을 이용하여 합친다. 이는 O(N) 과 O(NlogN) 등의 시간복잡도를 가지는 작업들이 따로따로 발생하기에, 가장 큰 시간복잡도 차수를 가지는 O(NlogN) 이 최종적인 시간복잡도라고 할 수 있다. 문제 해결 과정에서 inplace 정렬을 사용하나, lower 의 특성상 O(N) 의 공간복잡도를 가지게 된다.
### 📝 추후 개선점

  - 다른사람의 풀이를 살펴보면 같은 방식으로 푼 것이 대부분이였다. 다만 "" 과 '' 의 속도차이가 있나 알아보니, 결론적으로 차이가 없으며, 다만 PEP 8 가이드라인에 따라, 둘 중 하나만 일관성 있게 쓰는 것을 추천한다라는 것을 배우게 되었다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(my_string):
    return "".join(sorted(my_string.lower()))
```
