### [ Programmers ] 짝수 홀수 개수

### 🛠️ 풀이 접근 및 분석

  - **접근 1**
    - 짝수를 1, 홀수를 0으로 취급하는 삼항연산자를 통하여 리스트 컴프리헨션과 함께 sum 을 구하는 값, 반대로 짝수를 0, 홀수를 1로 취급하는 방식을 사용하여 괄호와 함께 반환하는 방식을 선택했다. 이렇게 한다면 한줄로 코드를 사용할 수 있지만, 지금 보니 과도하게 길며 가독성이 매우 떨어진다. num_list 를 순회하며 짝수 홀수를 판별하는데 O(N)의 시간복잡도가 발생하며, 합을 구하는 것도 별도로 O(N) 의 시간복잡도가 발생한다. 결론적으로는 전체적으로 O(N) 의 시간복잡도와 공간복잡도가 발생한다.

### 📝 추후 개선점
  - 다른 사람들의 풀이를 살펴보니, 두개의 값만 고정으로 가지는 배열을 사전에 초기화해둔 상태로, num_list 순회를 돌며, 맞는 조건을 만날 시에, 1을 더하는 방식을 사용한 것을 보았다. 이는 O(N) 의 시간복잡도를 가지는 것은 동일하지만, O(1)의 공간복잡도를 가진다라는 측면이 존재하며, 무엇보다 가독성이 뛰어나다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(num_list):
    return [ sum([ 1 if n % 2 == 0 else 0 for n in num_list ]), sum([ 1 if n % 2 == 1 else 0 for n in num_list ])]
```
