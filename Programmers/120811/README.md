### [ Programmers ] 중복된 문자열 제거

### 🛠️ 풀이 접근 및 분석

  - **접근 1**
    - 배열이 주어지면, 해당 배열을 정렬하고, 정렬된 배열상의 중앙값을 반환하면 된다. 여기서, 중앙값을 구하기 전에 내장 sort 를 사용하고, len() 을 이용하여 길이를 계산한 후 연산자를 이용해 중앙값을 계산하여 반환한다면, 정렬된 배열을 만드는데 O(N log N) 의 시간복잡도가 발생하며, 정렬된 배열을 저장하는데 O(N) 의 공간복잡도가 발생한다.

### 📝 추후 개선점

  - 다른 사람들의 풀이를 살펴보니, 코드는 동일하지만, 배열의 길이를 살펴보려는 과정에서는 정렬된 배열의 길이나 정렬 전의 길이나 동일하다는 점을 고려하여 return 뒤의 한줄로 코드를 끝내버린 코드가 존재한다. 전체적인 시간복잡도는 O(N log N), 공간복잡도도 O(N) 으로 동일하겠지만, 실질적으로 유의미한 성능 차이가 있다라고 하기는 힘들다. 하지만 가독성 측면에서는 개선되었다는 부분이 존재한다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(array):
    array = sorted(array)
    return array[len(array)//2]
```
