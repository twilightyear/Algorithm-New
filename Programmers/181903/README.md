### [ Programmers ] qr code

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
  - code 의 인덱스에 대하여 q 로 나누었을때 r 을 만족하는 인덱스의 해당 값들을 이어 반환하면 되는 문제이다. for 문을 통하여 순회하며, 조건문을 통하여 결과값을 위하여 미리 초기화해둔 빈 문자열에 더해주고, 마지막에 반환하면 쉽게 해결 가능하다.

### 📝 추후 개선점

  - 다른사람의 풀이를 살펴보던 도중, 매우 뼈를 때리는 답안을 보게 되었다. 바로, 단순히 code[r::q] 로 해결하는 방식이 존재했다. 애초에, 문제를 해석해보면, 애초에, code 의 인덱스를 q 로 나누는 과정 자체가, q 간격으로 반복되는 의미를 가지는데, 이러한 "문자열의 반복" 이라는 점에 집중하여, 슬라이싱으로 간편하게 해결하는 방식이 있다는 것이다. 최종적인 시간복잡도와 공간복잡도는 최악의 경우 O(N) 으로 동일하지만, 상수시간 내에서의 효율성을 따져보자면 슬라이싱이 더 빠를 것이라는 생각이 들었다. 문제가 시키는 그대로 해보는 것도 중요하지만, 문제 자체를 거시적으로 바라보는 관점을 길러야 할 것 같다.

### 💻 풀이 코드

```python
#풀이 1
def solution(q, r, code):
    answer = ''
    for i in range(len(code)):
        if i % q == r:
            answer+=code[i]
    return answer
```
