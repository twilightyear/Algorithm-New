### [ Programmers ] 소문자로 바꾸기

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 상당히 쉬운 문제이다. 파이썬답게 풀기 위해서 lower() 함수를 적용하다면 바로 return 할 수 있다.

### 📝 추후 개선점
  - 다른 사람들의 풀이를 보던 와중, replace 를 사용하여 광기의 풀이를 적어낸 사람이 있는것을 보았다. 설마 싶어서, 이게 더 빠른건가 해서 찿아보니.. 전혀 그런건 존재하지 않았다. 여전히 lower() 자체로 사용하는 것이 효율적인 동작이였다. 이외에도 아스키를 활용하여 연산하고 변환하는 풀이 또한 존재했지만, 여전히 파이썬에서는 내장 lower() 를 사용하는 것이 효율적이다. O(N) 의 시간복잡도와 공간복잡도를 가지나, 상수 시간 내에서의 시간 개선이라는 측면에서, 다른 replace, 아스키 풀이법(오버헤드 발생..) 과 비교하자면, 빠른 편이라고 말할 수 있다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(myString):
    return myString.lower()
```
