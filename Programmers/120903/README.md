### [ Programmers ] 배열의 유사도

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 두 배열간 공통 항목이 몇개 있는지 확인하는 것이 핵심이다. 두 배열은 중복된 원소를 가지지 않는다고 문제에서 제약조건을 걸어두었으니, set 을 사용하여 집합을 만든다고 해도 원소의 개수와 구성이 달라지지 않는다. 여기서 만들어진 두 집합에 대한 교집합을 교집합 연산자 & 를 통하여 구해주고, 길이를 반환해준다면, s1 의 원소 개수 N 과 s2 의 원소 개수 M 에 대하여, 평균적인 경우 O(N+M) 의 공간복잡도와 시간복잡도를 가지게 된다.

### 📝 추후 개선점
  - 두 배열은 중복된 원소를 가지지 않는다고 했으니, s1 만 집합으로 변형하고, s2 는 순회를 하며 s1 와 비교하는 방식으로 구성한다면, s1 의 원소의 개수 N, s2 의 원소의 개수 M 에 대하여 평균적인 경우 O(N+M) 의 시간복잡도를 가지는 것은 동일하지만, O(N) 의 공간복잡도를 가지도록 메모리 효율성을 개선할 수 있다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(s1, s2):
    return len(set(s1) & set(s2))
```
