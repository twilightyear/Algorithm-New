### [ Programmers ] 잘라서 배열로 저장하기

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - for 문을 통한 n 값 루프 및 문자열 슬라이싱을 통하여 한줄로 간편하게 풀 수 있었다. 이렇게 한다면 최악의 경우, 슬라이싱은 복사본을 만들어내니 문자열 my_str 의 길이 N 에 대하여 O(N)의 시간복잡도와 공간복잡도를 가지게 된다.

### 📝 추후 개선점
  - 현재 풀이는 시간 복잡도 및 공간복잡도가 O(N) 이며, 충분히 효율적인 풀이 방식이다. 일반적인 관점에서는 점근적인 복잡도를 개선하기 힘들지 않을까라고 생각한다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(my_str, n):
    return [ my_str[i:i+n] for i in range(0, len(my_str), n) ]
```
