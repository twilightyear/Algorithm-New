### [ Programmers ] 배열 원소의 길이

### 🛠️ 풀이 접근 및 분석

  - **접근 1**
    - 리스트의 값들의 길이를 전부 배열에 저장하여 반환하면 되니, 초기화해둔 배열에, 리스트의 항목을 순회하며 len() 을 통하여 길이를 측정하고 저장한다. 이는 배열의 길이 N에 대하여 O(N) 의 시간복잡도와 O(N) 의 공간복잡도를 가진다.
### 📝 추후 개선점
  - 다른사람의 풀이를 살펴보며, list, map 을 사용하여 훨씬 간결하게 풀이한 방식을 살펴보았다. 이는 결론적으로는 동일한 시간/공간복잡도를 가지지만, for 문을 통한 순회를 통한 풀이방식 보다는 미세하게라도 적은 오버헤드가 발생하기 떄문에, 조금이라도 더 효율적이면서, 무엇보다 더 간결한 풀이방식이라고 할 수 있다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(strlist):
    answer = []
    for word in strlist:
        answer.append(len(word))
    return answer
```
