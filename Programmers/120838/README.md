### [ Programmers ] 모스부호 (1)

### 🛠️ 풀이 접근 및 분석
-   **접근 1**
 - 먼저, morse dict 테이블을 만든 후, 입력받는 Letter 를 모스 단위로 분해한 후, 분해한 단어를 dict 테이블에서 조회하도록 리스트 컴프리헨션과 함께 구성했다. 이렇게 한다면 letter 의 길이 N 에 대하여 최악의 경우에도 O(N) 의 공간복잡도와 시간복잡도를 가지게 된다.

### 📝 추후 개선점
  - 본 풀이에서 굳이 리스트 컴프리헨션을 사용하지 않고도, 대괄호를 제거하여 제너레이터 표현식을 사용할 수 있다. O(N) 의 공간복잡도와 시간복잡도는 변하지 않지만, 상대적인 공간 사용량을 줄일 수 있다는 장점이 존재한다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(letter):
    morse = { 
        '.-':'a','-...':'b','-.-.':'c','-..':'d','.':'e','..-.':'f',
        '--.':'g','....':'h','..':'i','.---':'j','-.-':'k','.-..':'l',
        '--':'m','-.':'n','---':'o','.--.':'p','--.-':'q','.-.':'r',
        '...':'s','-':'t','..-':'u','...-':'v','.--':'w','-..-':'x',
        '-.--':'y','--..':'z'
    }
    
    return ''.join([morse.get(c) for c in letter.split(' ')])
```
