### [ Programmers ] 개미 군단

### 🛠️ 풀이 접근 및 분석
  - **접근 1**
    - 그리디 알고리즘을 적용하여, 총 병력수가 적은 방향을 고려하기 위해서는 가장 효과가 좋은 장군개미, 병정개미, 일개미 순으로 최대한 채워서 목표 수치를 달성하게 하면 된다. 일개미는 1만큼의 수치를 차지하기도 하며, 문제에서는 딱 맞춰서 목표수치를 맞추고 싶다고 미리 정의를 해두었기에, 단순 연산으로 개미종류별 개수를 구할 수 있다. 이렇게 한다면, 입력값이 달라지더라도, 결국 연산으로 작동 및 고정된 공간에 저장이 일어나니, O(1) 의 시간복잡도와 공간복잡도를 가진다고 할 수 있다.

### 📝 추후 개선점
  - 다른사람들의 풀이를 찿아보니, 나랑 동일한 풀이방식을 사용했지만, return 에 전부 한줄로 압축한 풀이방식, divmod 를 사용하여 5, 3, 1 을 순회하며 계산하는 방식들이 존재했다. return 에 전부 한줄로 넣는다면 O(1) 의 시간복잡도와 공간복잡도를 가진다는 사실은 변하지 않지만, 개미 종류별 개수를 저장하는 3개의 변수를 따로 저장할 필요가 없다는 점에서 조금이나마 공간 절약을 할 수 있을 것이다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(hp):
    g = int(hp/5)
    s = int((hp-g*5)/3)
    w = hp-g*5-s*3
    return g+s+w
```
