### [ Programmers ] 문자 반복 출력하기

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 문자열의 각 문자에 대하여 n 만큼 반복하여 출력하면되는 매우 간단한 문제이다. result 를 빈 문자열로 초기화 한 후, for 문을 사용하여 모든 문자에 대하여 n 만큼 곱하여 출력하게 하는 파이썬다운 방식으로 풀이를 한다면 문자열의 길이 N 과 반복횟수 M, 최종 출력 문자열의 길이 L(M*N) 에 대하여 최악의 경우 O(L^2) 의 시간복잡도와 O(L)의 공간복잡도를 가진다.

### 📝 추후 개선점
  - 다른 사람들의 풀이를 이번에도 살펴보니, join 을 사용하여, 즉

  ```
  ''.join(i*n for i in my_string)
  ```

  을 통하여 해결하는 방식이 인상깊었다. 이 방식을 사용한다면 O(L) 의 시간복잡도와 공간복잡도를 가지게 되며, 시간복잡도 측면에서 적은 시간 개선이 이루어 질 수 있을 것이며, 무엇보다 더 파이썬답고 간결하다.


### 💻 풀이 코드

```python
# 풀이 1
def solution(my_string, n):
    result = ""
    for c in my_string:
        result += c*n
    return result
```
