### [ Programmers ] 부분 문자열

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 처음 보자마자 KMP 알고리즘을 써야하나 생각을 했다. 하지만, 파이썬에서는 부분 문자열 문제를 in 을 사용하여 빠르게 풀 수 있다는 점을 고려하여 쉽게 접근을 했다. str1 in str2 를 통하여 간단하게 확인 할 수 있다. 각 문자열의 길이 N, M 에 대하여 최악의 경우 O(N*M) 의 시간복잡도를 가질 수 있다. 공간복잡도는 O(1) 를 가진다.

### 📝 추후 개선점
  - 다른 사람들의 풀이를 살펴보니, if 문이 아닌, int() 를 씌어주어 푸는 방식을 발견했다. 시간복잡도와 공간복잡도는 기본적으로 동일하지만, 이렇게 푼다면 분기문이 없다는 점에서, 미세하게라도 더 빠르게 풀이가 된다는 사실을 깨달았다. 항상 느끼지만, 쉬운문제라도 다른 사람의 풀이를 보다보면 배워가는 것이 항상 있는 것 같다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(str1, str2):
    return 1 if str1 in str2 else 0
```
