### [ Programmers ] n의 배수 고르기

### 🛠️ 풀이 접근 및 분석
  - **접근 1**
    - numlist 를 조회하며, n 으로 나누어 떨어지는지 확인하는 과정을 리스트 컴프리헨션으로 압축한다면, 최악의 경우 numlist 의 길이 N 에 대하여 O(N) 의 공간복잡도와, 시간복잡도를 가지게 된다.

### 📝 추후 개선점
  - 가독성을 개선하기 위하여 리스트 컴프리헨션을 풀어서 사용할 수 있겠지만, 이렇게 풀이한다면 시간복잡도 및 공간복잡도를 동일하게 가지는 것 처럼 보여도 미세하게나마 오버헤드가 발생하여 조금이라도 더 느려질 경우가 존재할 수 있다. 그렇기에, 현재 풀이가 코딩 테스트 풀이로는 적합한 형태라고 생각한다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(n, numlist):
    return [num for num in numlist if num % n == 0]
```
