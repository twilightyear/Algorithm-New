### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 이중 중첩 삼항 연산자와 내부 리스트 컴프리헨션을 사용하여 한줄로 풀이할 수 있었다. 간단하게 in 을 통하여 존재여부를 파악하고, 없다면 id 가 리스트 컴프리헨션을 통하여 추출한 2차원 배열 내의 항목의 첫값으로만 다시 만든 리스트에 없다면 최종적으로 fail 을 출력하게 구성했다. db 의 길이 N 에 대하여 O(N) 의 시간복잡도와 공간복잡도를 가진다.

### 📝 추후 개선점
  - 다른 사람들의 풀이를 살펴보니 매우 좋은 표현식을 하나 배웠다. Python 3.8 부터 사용 가능한 일명 바다코끼리 연산자 := 이다. 사실상 풀이는 접근 1번을 풀어서 쓴 내용이라 크게 달라질 것은 없었지만, := 을 통하여 대입과 비교를 동시에 하는 방식으로, 속도 측면에서 큰 차이는 없지만, 가독성 측면에서 나쁘지 않다고 할 수 있다. 단독으로 := 를 사용하면 일반 대입연산자와 다를바가 없지만, 비교와 함께 사용하면 동시에 처리를 해주는 기능을 배우게 되었다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(id_pw, db):
    return "login" if id_pw in db else ("fail" if id_pw[0] not in [row[0] for row in db] else "wrong pw")
```
