### [ Programmers ] 문자열안에 문자열

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 삼항연산자와 in 연산자를 통하여 문자열이 다른 문자열 안에 포함되어있는지 쉽게 확인할 수 있다. 이렇게 한다면 O(1) 의 공간복잡도와, str1 의 길이 N, str2 의 길이 M 에 대하여 최악의 경우 O(N x M) 의 시간복잡도를 가질 수 있다.

### 📝 추후 개선점
  - 다른 사람들이 풀이한 내용을 보니, int(str2 in str1) 을 사용하여 bool 값을 정수로 바꾼 후, 정수 1 을 더하는 방식으로 1 혹은 2를 반환하게끔 구성한 것을 보았다. 이렇게 한다고 해서 시간복잡도와 공간복잡도의 측면에서의 개선은 크게 없다만, 신기하게 접근했다고 생각했다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(str1, str2):
    return 1 if str2 in str1 else 2
```
