### [ Programmers ] 배열 뒤집기

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 배열을 뒤집어라는 매우 간단한 문제이다. 바로 떠오른 풀이는 reverse() 함수를 사용하거나, 슬라이싱을 사용하는 방법이였는데, 슬라이싱을 사용한 풀이를 적용했다. 이렇게 한다면 문자의 길이 N 에 대하여 O(N) 의 시간복잡도와 O(N) 의 공간복잡도를 가지게 된다.

### 📝 추후 개선점
  - 풀이 접근에서 언급했든, reverse() 함수를 사용해도 풀 수 있다. 여기서, 슬라이싱을 사용하면 복사가 일어나기에 O(N) 의 공간복잡도를 가지며, reverse() 도 동일할 줄 알았지만, reverse() 는 in-place reverse 가 발생하기에, O(1) 의 공간복잡도를 가지며, 단순 슬라이싱으로 뒤집는 방식보다 공간적으로 효율적이라는 방식이라는 것을 알게 되었다. 심지어, 내부적으로 C 레벨로 동작하기에, 슬라이싱 방식보다 상수 시간에 대해서도 빠르다. 슬라이싱 방식은 원본을 유지하기에, 원본 유지가 필요한 상황에서는 유용하지만, 이번 문제처럼 원본파괴가 상관없는 상황에서는 reverse() 가 속도,공간 측면에서 모두 우수하다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(num_list):
    return num_list[::-1]
```
