### [ Programmers ] 7의 개수

### 🛠️ 풀이 접근 및 분석

  - **접근 1**
    - array 의 모든 요소를 순회하며, str 로 변환한 후, 7의 개수를 직접 세는 접근을 했다. array 의 원소는 커봤자 최대 6자리이다. 그렇기에, array 원소의 개수 N 개에 대하여 O(6*N), 즉 O(N) 의 시간복잡도를 가진다. 그리고, O(N) 의 공간복잡도를 가진다.

### 📝 추후 개선점

  - 다른 사람들의 풀이를 살펴보니, str(array).count('7') 를 사용한 풀이를 발견했다. 이는 결과적으로 접근 1번과 동일한 O(N) 의 시간복잡도 및 공간복잡도를 가지지만, 내장함수로써 돌아간다는 특성 덕분에 상대적으로 빠른 동작을 기대할 수 있다. 무엇보다 더욱 간결하다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(array):
    result = 0
    for c in str(array):
        if c == '7':
            result += 1
    return result
```
