### [ Programmers ] 짝수의 합

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 주어진 숫자까지의 짝수의 합을 구하면 되는 문제이다. 리스트 컴프리헨션을 사용하여 빠르고 간편하게 풀이할 수 있었다. O(N) 의 시간복잡도와 공간복잡도를 가진다.

### 📝 추후 개선점
  - 굳이 리스트 컴프리헨션을 쓸 필요없이, 아래와 같이로도 간편하게 풀이가 가능하다는 것을 다른사람들의 풀이를 보면서 알게 되었다.

  ```
  sum(range(0, n + 1, 2))
  ```

  시간복잡도는 O(N) 로 동일하나, 공간복잡도를 O(1) 로 개선할 수 있으며, 더 직관적이고 간단한 코드라고 할 수 있다는 점이 인상깊었다.


### 💻 풀이 코드

```python
# 풀이 1
def solution(n):
    return sum([i for i in range(n+1) if i % 2 == 0])
```
