### [ Programmers ] 최댓값 만들기 (2)

### 🛠️ 풀이 접근 및 분석

  - **접근 1**
    - 곱했을때 가장 큰 값을 구하면 되는 것이며, 조건에서 항상 원소의 개수는 2개 이상이니, 오름차순 정렬을 한 후 가장 마지막 원소 두개를 곱하면 된다고 생각했지만 생각해보니 음수와 음수의 곱셈도 양수가 될 수 있으니 가장 작은 서로 다른 두 원소를 곱한 값과 가장 큰 서로 다른 두 원소 중 더 큰값을 반환하면 될 것이라고 생각했다. 정해진 인덱스에 대한 접근과, 계산된 두 값에 대한 비교는 O(1) 의 시간복잡도를 가지지만, 정렬에서 필연적으로 O(NlogN) 의 시간복잡도를 가지게 된다. 그리고 sorted 를 사용하여 새로운 변수에 재할당을 진행했기에 원소의 개수 N 개에 대하여 O(N) 의 공간복잡도를 가지게 된다.

### 📝 추후 개선점

  - 다른 사람들의 풀이를 살펴보며, 가장 많은 좋아요를 받은 풀이를 살펴보니 아주 사소한 하나를 제외하고는 완전 동일한 코드였다. 다른 부분은 다름이 아닌 변수명 arr 이였다. 문제를 풀고 제출하고 다시 생각해보니 굳이 arr 에 새로 정렬된 요소들을 할당할 필요가 전혀 없었다. 기존의 numbers 원시값들이 필요한 문제가 전혀 아니니 더욱 그러했다. 이렇게 numbers 를 inplace 정렬을 한다고 가정해보면 O(NlogN) 의 시간복잡도는 동일하지만, 기존 O(N) 의 공간복잡도에서 O(1) 의 공간복잡도로 획기적인 공간 절감이 가능하다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(numbers):
    arr = sorted(numbers)
    return max(arr[-1]*arr[-2], arr[0]*arr[1])
```
