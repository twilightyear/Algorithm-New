### [ Programmers ] 외계행성의 나이

### 🛠️ 풀이 접근 및 분석
  - **접근 1**
    - dictionary 를 사용하여 미리 한자리 숫자들과 대응되는 알파벳을 지정한다. 10개만 사용하면 되니 굳이 알고리즘을 따로 구성하지 않았다. 여기서 리스트 컴프리헨션을 사용하여, 나이값을 문자열로 전환하고, 모든 자리에 대하여 dictionary 를 사용한 변환을 해준다면 나이 문자열의 자리수 N 개에 대하여 O(N) 의 공간복잡도와 시간복잡도를 가지게 된다.

### 📝 추후 개선점
  - 다른사람들의 풀이를 찿아보니, dictionary 를 따로 만들지 않고, 나이를 문자열로 변환한 후, 단순 replace 함수를 10번 사용하여 직관적이게 풀이 한 것을 인상깊게 보았다. 그렇지만 결국 시간복잡도와 공간복잡도는 나이 문자열의 자리수 N 에 대하여 O(N) 의 시간복잡도와 공간복잡도를 가진다. 코드 테스트의 관점에서 벗어나 확장성을 고려한다고 했을때는 내가 풀이한 방식인 dictionary 방식이 적절해 보인다. 항상 느끼는 것이지만, 아무리 간단한 문제여도, 최소한 작은 부분에서라도 사람마다 푸는 방식이 조금씩 다르다는 것을 느낀다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(age):
    dictionary = {
        "0": "a",
        "1": "b",
        "2": "c",
        "3": "d",
        "4": "e",
        "5": "f",
        "6": "g",
        "7": "h",
        "8": "i",
        "9": "j"
    }
    return "".join(dictionary.get(c) for c in str(age))
```
