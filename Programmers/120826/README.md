### [ Programmers ] 특정 문자 제거하기

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - string 을 조작할 수 있는 replace 함수를 이용하여 간편하게 특정 문자를 "" 로 대체하는 방식으로 코드를 짠다면 동작할 것이다. 이는 O(N) 의 시간복잡도와 공간복잡도를 가진다.

### 📝 추후 개선점
  - 리스트 컴프리헨션과 join 함수를 이용하여 구현을 할 수도 있지만, 오버헤드가 발생할 여지가 더 많다는 점에서, O(N) 의 시간복잡도와 공간복잡도를 가진다는 점은 동일하지만, 미세한 성능차이가 발생한다. 하지만, 문제에서 요구하는 사항이 많아진다면 리스트 컴프리헨션 방식으로 전환할 필요가 있을 수 있다. 하지만 본 문제에서는 replace 를 그대로 사용하는 것이 좋아보이며, 다른 사람들 풀이를 살펴보는 과정에서도 효율적인 풀이는 전부 replace 방식을 사용했다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(my_string, letter):
    return my_string.replace(letter,"")
```
