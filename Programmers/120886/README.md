### [ Programmers ] A로 B 만들기

### 🛠️ 풀이 접근 및 분석

  - **접근 1**
    - 문제가 요구하는 내용은 결국 두개의 다른 변수들을 각각 정렬했을때 같은 값이 나온다면 참, 아니면 거짓으로 생각할 수 있다. 그렇기에, 내장함수 sorted 를 사용해서 정렬 및 비교한 값을 int 로 명시적 타입 변환을 해주었다. O(NlogN) 의 시간복잡도와 O(N) 의 공간복잡도를 가진다.

### 📝 추후 개선점

  - 다른 사람들의 풀이를 살펴보니 대부분 간결한 풀이 방식으로는 정렬을 사용했지만, Counter 를 이용한 풀이가 매우 인상깊었다. 이 방식을 사용한다면 결론적으로 평균적으로 O(N) 의 시간복잡도와, 서로 다른 알파벳의 개수 K 에 대하여 O(K) 의 공간복잡도를 가지나, 알파벳은 영소문자로 한정을 해두었으니 상수취급한다고 했을때 O(1) 의 공간복잡도를 가진다고 할 수 있다. 이는 시간복잡도와 공간복잡도 측면에서 바라본다면 접근 1번과 비교했을때 개선된 풀이 방식이라고 할 수 있다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(before, after):
    return int(sorted(before)==sorted(after))
```
