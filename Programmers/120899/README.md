### [ Programmers ] 가장 큰 수 찾기

### 🛠️ 풀이 접근 및 분석
  - **접근 1**
    - max 를 따로 구하고 index 를 다시 찿을 필요 없이, enumerate 기능으로 한번에 순회 및 인덱스 값 갱신을 할 수 있었다. 물론 따로따로 하는 방식도 결국 array 의 길이 N 에 대하여 O(N) 의 시간복잡도와 O(1) 의 공간복잡도를 가진다는 것은 동일하겠지만, 결국 이전 풀이 방식이 더 빠르게 동작할 것이라고 기대해 볼 수 있다.

### 📝 추후 개선점
  - 다른사람들의 풀이를 찿아보니, index 함수를 이용하여, 최대값은 max 함수로 구한 후, index 함수로 따로 인덱스만 도출하는 방식을 적용한 것을 보았다. 이렇게 한다고 하면, 위에서 설명했던 시간/공간복잡도는 동일하면서도 표현코드가 엄청 간결해지긴 하지만, 그다지 효율적인 풀이방식이라고는 생각하긴 힘들었다. max 함수와 index 함수를 따로 사용하는 순간부터 접근 1번에서 하지 않았던 비효율적인 풀이와 같은 논리로 전개되는 것이다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(array):
    result = [array[0], 0]
    
    for i, num in enumerate(array):
        if num > result[0]:
            result[0] = num
            result[1] = i
    
    return result
```
