### [ Programmers ] 중복된 문자열 제거

### 🛠️ 풀이 접근 및 분석

  - **접근 1**
    - 중복된 문자열 제거에 있어서, 주어진 문자열을 순회하며, 별도의 초기화된 빈 배열에 값이 있는지 확인하고 없으면 추가하는 방식으로 진행하고 마지막에 join 을 통하여 문자열로 연결 및 반환하도록 접근했다. 이 방식으로는 최악의 경우 문자열의 길이 L 에 대하여 O(L) 의 공간복잡도를 가지지만 O(L^2) 의 시간복잡도를 가지게 된다.

### 📝 추후 개선점

  - 다른 사람들의 풀이를 살펴보니, 파이썬 3.7부터 dict 의 dict.fromkeys() 함수가 순서를 유지하며 중복을 제거하는 기능이 추가된 것을 활용하여 간결하게 한줄로 풀이한 방식을 보게 되었다. 이 방식을 사용한다면 문자열의 길이 L 에 대하여 O(L) 의 시간복잡도와 공간복잡도를 가지게 되어, 간결한것도 간결하지만, 시간/공간복잡도 측면에서도 상당히 개선된 모습을 가진다고 할 수 있다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(my_string):
    result = []
    
    for c in my_string:
        if c not in result:
            result.append(c)
    
    return ''.join(result)
```
