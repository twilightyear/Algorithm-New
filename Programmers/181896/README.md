### [ Programmers ] 첫번째로 나오는 음수

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 첫번째로 나오는 음수를 찿아야하는 문제인 만큼, O(N) 의 시간복잡도를 가지면 전체 순회는 필수적이다. for 문을 사용하여 순회를 진행하면, 처음으로 음수를 만나면 바로 인덱스를 반환하는 방식으로 구성하고, 끝까지 도달했다면 찿지 못했다는 의미를 가지니, -1 를 마지막에 반환하면 된다.

### 📝 추후 개선점
  - 조금 더 파이썬답게 풀기 위해서는 enumerate() 를 이용하여 i 값과 i 인덱스에 해당하는 값을 한번에 조회한다면 동일한 시간복잡도를 가지지만, 상수시간 내에서의 시간 차이로 봐서는, 인덱스에 대한 조회시간이 없어지니, 조금 더 빠르게 코드가 작동될 여지가 존재한다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(num_list):
    for i in range(len(num_list)):
        if num_list[i] < 0:
            return i
    return -1
```
