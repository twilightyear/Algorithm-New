### [ Programmers ] 문자열의 앞의 n글자

### 🛠️ 풀이 접근 및 분석
  - **접근 1**
    - 문자열의 앞의 n 글자를 구하면 되는 문제이다. 리스트 슬라이싱을 사용한다면 바로 정답을 구할 수 있다. 문자열의 길이 N 에 대하여, 최악의 경우 O(N) 의 시간복잡도와 공간복잡도를 가진다.

### 📝 추후 개선점
  - 다른사람들의 풀이를 찿아보니, 풀이 결과 자체를 람다 표현식으로 작성한 것을 보았다. 솔직히 말하면, 기초적인 람다 표현식은 해석할 수 있다지만, 조금만 복잡해져도 머리를 감싸쥐게 되는 경향이 있는 것 같다. 람다 표현식 자체도 실무에서 자주 사용되는 간편한 방식인 만큼 사용해보는 경험을 쌓아서 손에 익혀놓아야겠다는 생각을 했다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(my_string, n):
    return my_string[:n]
```
