### [ Programmers ] 숫자 찿기

### 🛠️ 풀이 접근 및 분석

  - **접근 1**
    - 주어진 숫자를 문자열화하여 인덱스 기반으로 조회하고, k 값과 동일한 값을 만났을때 해당 인덱스를 반환하고 바로 return 하게 하며, 못만났을 경우에서는 마지막에 -1 를 return 하게 만들었다. num 을 문자열화하는데는 최악의 경우에 O(N) 의 시간복잡도 및 공간복잡도가 발생하며, range 로 순회하는 상황에서도 최악의 경우에서는 O(N) 의 시간복잡도가 별도로 발생하지만, 전체적으로 바라보면 O(N) 의 시간복잡도 및 공간복잡도가 발생한다.
### 📝 추후 개선점

  - 다른 사람들의 풀이를 살펴보니, 그냥 단순하게 str 로 문자열화 한 후, find() 함수를 이용하여 한줄로 풀이한 버전을 인상깊게 보았다. 이렇게 풀이한다면, 접근 1번 처럼, O(N) 의 시간복잡도와 공간복잡도가 발생하는건 마찬가지지만, find 내부함수를 사용한다면 미세하지만 조금 더 빠른 속도를 기대해 볼 수 있다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(num, k):
    n = str(num)
    for i in range(len(n)):
        if n[i] == str(k):
            return i + 1
    return -1
```
