### [ Programmers ] 문자열 정렬하기 (1)

### 🛠️ 풀이 접근 및 분석

  - **접근 1**
    - 문자열과 숫자를 구분하는 방식이 핵심이라고 생각했다. isnumeric() 함수를 사용하여 리스트 컴프리헨션 내부에서 for 문을 사용한 전개에서 문자/숫자를 필터링하여 리스트를 제작하여 바로 정렬을 하고 반환하도록 접근했다. 이렇게 한다면 반환용 리스트에 있어서 최악의 경우 최초 문자열의 길이 N 에 대하여 O(N) 의 시간복잡도와 공간복잡도를 가지게 된다.

### 📝 추후 개선점

  - 다른 사람들의 풀이를 살펴보니 정규식을 활용한 풀이, 틀은 동일하지만 isnumeric() 대신 isdigit() 함수를 이용한 풀이, 일일히 로직을 길게 짠 방식등이 존재했다. 사실 본 코드에서는 아무생각없이 c.isnumeric() == 1 이라고 적은 부분이 존재했다. 하지만 생각해보니 굳이 필요가 전혀 없었다. c.isnumeric() 자체만 사용해도 무방한 것이였다. 이러한 사소한 디테일들을 신경을 항상 써야겠다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(my_string):
    return sorted([ int(c) for c in my_string if c.isnumeric() == 1 ])
```
