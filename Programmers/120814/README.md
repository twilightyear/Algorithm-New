### [ Programmers ] 피자 나눠 먹기 (1)

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 단순 계산으로 n/7 한 값에 올림을 적용하면 풀리는 문제이다. O(1) 의 공간복잡도와 시간복잡도를 가진다.

### 📝 추후 개선점
  - 단순 정수의 연산을 활용하여 (n + 6) // 7 의 방식으로도 접근 할 수 있으며, 이를 통하여 부동소수점 단위의 연산을 하지 않아도 된다는 장점이 존재한다.

### 💻 풀이 코드

```python
# 풀이 1
import math

def solution(n):
    return math.ceil(n/7)
```
