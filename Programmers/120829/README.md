### [ Programmers ] 각도기

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - 각의 값에 따라, 예각, 둔각, 직각, 평각을 숫자로 구분하는 문제이다. 굳이 길게 쓸 필요 없이 중첩된 삼항연산자로 풀이한다면 한줄로 간편하게 풀 수 있다라고 생각하고 접근했다. O(1) 의 시간복잡도와 공간복잡도를 가진다.

### 📝 추후 개선점
  - 다른사람들의 풀이를 살펴보다 매우 신기한 풀이를 발견했다. 단순 if 문을 사용한 것이 아닌, 각의 연산을 사용하여 1~4 사이의 지정값을 구하는 방식을 사용하는 모습을 보였다. 문제 특성상 대부분의 풀이들은 O(1) 의 시간복잡도와 공간복잡도를 가진다고는 하지만, 넓게 바라보는 풀이 방식이라는 점이 매우 인상깊었다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(angle):
    return 1 if 0 < angle < 90 else 2 if angle == 90 else 4 if angle == 180 else 3
```
