### 🛠️ 풀이 접근 및 분석
-   **접근 1**
 - 정석적으로 my_string 의 모든 char 값을 하나하나 순회하며, 미리 정의해둔 모음 배열에 없는 단어만 초기화해둔 result 에 추가하도록 구성했다. 최악의 경우 my_string 의 길이 N 에 대하여 O(N) 의 공간복잡도가 발생하며, 문자열 연장에서 O(N^2) 의 시간복잡도가 발생한다.

### 📝 추후 개선점
  - 다른사람들의 풀이를 보며, 모음 배열을 "aeiou" 로 구성해서 굳이 배열을 사용하지 않는 방법이 인상깊었으며, 또한, 이번 풀이에서는 시도하다가 잘 구성이 안되서 그냥 사용하기를 포기한 리스트 컴프리헨션을 사용한 방식 또한 위의 문자열로 구성한 방식과 함께 사용한 것이 매우 인상깊었다. 공간복잡도 측면에서 O(N) 의 복잡도를 가진다는 것은 동일하지만, 시간복잡도를 O(N) 으로 개선할 수 있다는 점과, join() 을 사용한다는 점과 오버헤드가 적게 발생한다는 점에서 조금이나마 효율적일 것이다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(my_string):
    vowels = ['a','e','i','o','u']
    result = ''
    for char in my_string:
        if char not in vowels:
            result += char
    return result
```
