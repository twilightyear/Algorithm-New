### [ Programmers ] 점의 위치 구하기

### 🛠️ 풀이 접근 및 분석

-   **접근 1**
 - x 와 y의 양수 음수의 여부에 따라 사분면을 결정하면 되는 아주 간단한문제이다. 따로 복잡할 로직을 짤 필요 없이, 경우의 수에 따른 구분을 모조리 해주었다. 이렇게 한다면 O(1) 의 시간복잡도와 공간복잡도가 발생하게 된다. 

### 📝 추후 개선점
  - 다른사람들의 풀이를 살펴보던 중 대활호에 tuple을 사용하여 사분면 구분값을 넣어주고, 간단한 비교식으로 간결한 풀이를 작성 한 것들 보았다. 이렇게 한다고 해도 결국 O(1) 의 시간복잡도와 공간복잡도를 가지는 것은 동일하지만, 간결하고 신박한 접근법이라는 것이 인상깊었다.

### 💻 풀이 코드

```python
# 풀이 1
def solution(dot):
    x, y = dot
    if x > 0 and y > 0:
        return 1
    elif x > 0 and y < 0:
        return 4
    elif x < 0 and y > 0:
        return 2
    elif x < 0 and y < 0:
        return 3
```
